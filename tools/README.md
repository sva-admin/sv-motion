# tools (mirror)

These three scripts, `phone-shots.mjs`, `stills.sh` and `make-sound.sh`, are mirrors of the blocks under "Helper scripts" in [`../SKILL.md`](../SKILL.md). They stay here only so old links keep working.

`SKILL.md` is the source of truth. An agent writes each script from that file into the project's `tools/` folder when a step needs it, so nobody has to fetch this folder. If a script changes, change it in `SKILL.md` first, then copy it here byte for byte.
